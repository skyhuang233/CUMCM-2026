# 执行层采用 DP 价值执行器，不用储能滚动 LP，紧急购电不用于充电

问 2–4 的执行层原为 48h 点预测下每段重解的储能滚动 LP（允许紧急购电给储能充电）。全年固定同一计划购电流的对照显示它比最简单的贪心规则还多花 3.75%（1447.9 vs 1393.6 万元）：点预测驱动的 LP 几乎每晚按 5 倍电价囤电，预测失准时这些电就是白花的钱；而附件式 DP 价值执行器再比贪心省 1.0%（1379.5 万元）。因此执行层改为：日前用同批场景反推未来费用函数得到每段动态保留水平，逐段做一维投影；紧急购电只补当段缺口。放电侧用乐观的未来价值只会更保守，充电侧用它会系统性高估囤电价值，这是禁止紧急充电的原因；「允许紧急充电」只作为附录变体实验。

原滚动 LP 与贪心规则保留为论文对照执行器，不再进入主流程；不要以「LP 更优化」为由把它换回来——数据已经否定了这一点。
