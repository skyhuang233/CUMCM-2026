\begin{abstract}

本文研究带储能的非孤岛微网在``先承诺、后兑现''交易结构下的购电调度问题。微网运营商须在每日凌晨信息高度不完整时承诺全天144个时段的购电量，承诺不可更改，缺口由5倍电价的紧急购电补足。储能是唯一的跨时段调控手段，但容量有限、充放电有效率损耗。问题的核心矛盾在于：承诺刚性与需求不确定之间的冲突，以及``买多浪费''与``买少受罚''之间的成本不对称。

本文构建了一套统一的``预测/场景层$\to$购电决策LP$\to$储能滚动控制$\to$结算''框架，四问共用同一LP优化核，逐问仅改变信息输入而不改变决策结构。

\textbf{问1}：在完美信息下建立确定性线性规划，得到全天最优购电费35\,127元作为费用下界，其中周期约束的对偶价格0.47元/kWh揭示了储能的边际价值。

\textbf{问2}：引入walk-forward预测与经验残差联合场景，构建SAA两阶段代理模型：购电量在承诺阶段跨场景共享，储能追索按场景分开。采用48h时域代替传统的周期约束，使储能的跨日转移成为经济决策。执行阶段由因果滚动LP控制储能——每10分钟以当段真值和剩余时域点预测重新规划，只执行首段。全年总费用1\,448万元，相较完美信息下界高18.4\%，此即不确定性条件下的结构性``信息租金''。

\textbf{问3}：利用6:00/12:00/18:00整点光伏预报，构建含调整变量$\Delta^{\pm}$的重优化LP。重优化用1.5倍电价的增购替代5倍惩罚的紧急购电，将最优承诺的临界分位从80\%降至约70\%。全年总费用降至1\,396万元（$-3.6\%$）。逐时刻边际价值分析表明：6:00贡献40万元、12:00贡献30万元、18:00仅6万元。

\textbf{问4}：将电价纳入不确定性，扩展为负载--光伏--电价三通道联合场景。波动电价使全年费用增加约5\%，但其中仅1/7（约10万元）来自预测不准，其余6/7是价格波动本身在任何信息条件下均不可避免的结构性代价。

敏感性分析表明48h时域与72h的费用差仅0.004\%，场景数从12增至20仅再改善0.34\%，验证了模型参数的稳健性。本文的核心发现可转化为运营建议：少量高频的紧急购电是不对称惩罚下最优风险配置的必然结果，不应作为绩效惩罚指标；预报资源应优先投入6:00和12:00的光伏预报更新。

\keywords{微网购电调度\quad 两阶段随机规划\quad 样本平均近似\quad 因果滚动控制\quad 储能优化}
\end{abstract}

\section{问题分析与研究框架}
%===================================================================

\subsection{问题背景：微网购电的``先承诺、后兑现''结构}

本题研究的是一个连接外部电网的微网系统，其供电来源包括向外网购电、分布式光伏发电和储能设备。微网运营商面临的核心决策是：在每日凌晨0:00，为全天144个10分钟时段确定向外网的购电量，该购电量一经提交即不可更改。

这一交易结构的关键特征在于\textbf{信息不对称与承诺刚性的矛盾}：运营商在承诺购电量时，小区负载需求和光伏发电量均尚未实现，仅能依赖历史数据进行预测；而一旦承诺，即便事后发现购电量与实际需求不匹配，也无法修改。当实际供给不足时，只能以5倍电价紧急购电补足缺口；当供给过剩时，多余电量无法回售，产生浪费。

\subsection{三组核心矛盾}

深入分析题目结构，可以将问题提炼为三组核心矛盾：

\begin{enumerate}
\item \textbf{承诺刚性与需求不确定}。日前冻结的购电量$G^0_t$不可更改，但负载和光伏均存在预测误差。这意味着确定性优化（仅使用点预测）无法充分利用不确定性的分布信息，必须引入随机优化框架。

\item \textbf{成本不对称与双向风险}。买多1~kWh的代价是浪费了约0.47元（附件1平均电价下），买少1~kWh的代价是以5倍电价紧急购电（约7元/kWh在峰段）。这种约15:1的不对称惩罚决定了最优购电量不应是需求的期望值，而应偏向需求分布的高分位数。

\item \textbf{储能的时间价值与容量约束}。储能可在低价段充电、高价段放电实现时间套利，但受制于容量限制（$1200 \leq S_t \leq 10800$~kWh）和效率损耗（充电乘0.9、放电除以0.9）。这种跨时段耦合使得贪心规则不可行，必须进行多段联合优化。
\end{enumerate}

\subsection{四问的递进关系与统一框架}

四问并非四个独立的问题，而是同一个决策系统在信息条件逐步接近现实时的演化：

\begin{itemize}
\item \textbf{问1}（完美信息下界）：负载、光伏、电价全部已知，求确定性最优——这是后续所有策略的费用基准。
\item \textbf{问2}（不确定性下的日前承诺）：负载和光伏需要预测，购电量在凌晨0:00一次性承诺——衡量不确定性带来的结构性代价。
\item \textbf{问3}（日内信息更新）：在6:00/12:00/18:00获得新的光伏预报后，可对购电量进行有代价的调整——衡量日内信息的经济价值。
\item \textbf{问4}（三重不确定性）：电价也变为波动未知量——衡量电价不确定性的边际代价。
\end{itemize}

本文的核心设计决策是建立一套\textbf{统一的决策架构}，四问共用：

\begin{equation}\label{eq:framework}
\text{预测/场景层} \;\longrightarrow\; \text{购电决策LP（优化核）} \;\longrightarrow\; \text{储能滚动控制} \;\longrightarrow\; \text{费用结算}
\end{equation}

逐问改变的只是预测/场景层的输入内容（完美信息、点预测+残差场景、整点预报、电价预测），决策结构和求解方法保持不变。这种设计使得各问之间的费用差异可以被严格归因到信息条件的变化，而非模型结构的差异。图\ref{fig:framework}给出统一框架的数据流。

\subsection{信息假设}

\begin{assumption}\label{asu:info}
全程遵守因果性（walk-forward）原则：决策日$d$的任何预测与场景构建仅使用日期严格早于$d$的历史数据。每段$t$开始时，该段的负载$L_t$、光伏$PV_t$和电价$p_t$真值已知，未来段仅有点预测。
\end{assumption}

\begin{assumption}\label{asu:storage}
储能设备在当天内可根据实时信息自由调度。题面仅冻结购电量并按其计费，未要求储能按日前计划运行。本文的充放电量与SOC均为因果执行值。
\end{assumption}

\begin{assumption}\label{asu:emergency}
紧急购电以$5p_t$计费后不限用途，可用于给储能充电。当预测到峰段缺口无法由储能覆盖时，在谷段紧急购电充电（$5\times0.42/0.81\approx2.6$~元/kWh）比峰段紧急购电（$\approx7$~元/kWh）更经济，是合理的应急调度策略。
\end{assumption}

\subsection{物理约束与能量平衡}

每个时段的能量平衡满足：
\begin{equation}\label{eq:balance}
G_t + E_t + PV_t + D_t = L_t + C_t + W_t
\end{equation}
其中左端为供给（购电+紧急购电+光伏+储能放电），右端为消耗（负载+储能充电+富余电量）。

储能的SOC动态为：
\begin{equation}\label{eq:soc}
S_t = S_{t-1} + 0.9\,C_t - D_t / 0.9, \quad S_t \in [1200,\, 10800] \text{~kWh}
\end{equation}
充电损耗系数0.9意味着充入交流侧1~kWh仅有0.9~kWh进入储能；放电损耗系数$1/0.9$意味着从储能取出0.9~kWh才能向交流侧释放$0.9/0.9=1$~kWh。一个完整的充放电循环保留$0.9\times0.9=81\%$的电量。

\subsection{费用结算规则}

\textbf{问2}：每段费用$\text{Cost}_t = p_t G^0_t + 5p_t E_t$。

\textbf{问3起}（引入调整购电$G^a_t$）：
\begin{equation}\label{eq:cost_q3}
\text{Cost}_t = p_t \min(G^0_t, G^a_t) + 0.5\,p_t\,(G^0_t - G^a_t)^+ + 1.5\,p_t\,(G^a_t - G^0_t)^+ + 5\,p_t\,E_t
\end{equation}
其经济含义为：减购时取消部分承担50\%违约损失，增购时超出部分按1.5倍购买。这一结构使得在缺口概率较高时，以1.5倍电价增购远优于以5倍电价紧急购电——重优化的价值正源于此。

\subsection{模型边界}

本模型有意省略以下现实机制：(1)~不考虑微网向外网售电的可能性；(2)~日类型仅分为两类（周五/周六型与其他日型），未细分节假日和极端天气；(3)~负载预测不利用日内已实现的部分段数据（附件3仅提供光伏预报，不提供负载更新信息）。这些简化的合理性在于：附件2数据验证了两类日类型对日负载电量的分离完全无例外（周五/周六型71.5--95.9~MWh，其他日型116.9--141.6~MWh），以及当前信息结构下负载的日内更新渠道确实缺失。

\section{完美信息下的最优调度（问1）}

\subsection{确定性线性规划的建立}

问1提供了一天的完整电价、负载与光伏数据，不存在不确定性。这使问题成为一个标准的确定性多段线性规划：

\begin{equation}\label{eq:q1obj}
\min \sum_{t=0}^{143} p_t G_t + \varepsilon \sum_{t=0}^{143} (C_t + D_t + W_t)
\end{equation}
满足约束\eqref{eq:balance}、\eqref{eq:soc}以及：
\begin{equation}
G_t \geq 0,\quad 0 \leq C_t, D_t \leq \bar P,\quad W_t \geq 0, \quad S_{143} = S_0 = 6000 \text{~kWh}
\end{equation}

目标函数中的正则项$\varepsilon\sum(C_t+D_t+W_t)$用于排除退化解中的同时充放电与无意义吞吐，对最优费用的影响小于0.1元。

\textbf{模型选择的推理}：该问题的物理结构——线性费用、线性平衡、线性SOC动态——天然具有线性规划的结构。LP不是因为``计算方便''而被选择，而是因为问题本身就是线性的。在此基础上，LP的全局最优性保证和对偶信息是额外的结构红利。

\section{不确定性下的日前购电决策（问2）}

\subsection{预测不确定性为什么使确定性LP不够}

若在问2中直接使用负载和光伏的点预测值求解确定性LP（即用期望曲线代替随机变量），所得购电量恰好等于预测需求的条件最优。但在5倍惩罚的不对称成本下，这个``期望最优''系统性地低估了实际费用：

\begin{itemize}
\item 当真值低于预测时，多余购电的浪费代价约为$p_t$量级（约0.42--1.40元/kWh）；
\item 当真值高于预测时，缺口的紧急购电代价为$5p_t$（约2.1--7.0元/kWh）。
\end{itemize}

由于``少买''的惩罚远大于``多买''的惩罚，最优策略应当偏向需求分布的高分位数。确定性LP无法``看到''这种不对称——它只能追踪期望值，而非分布的形态。因此，必须引入能够内化误差分布的随机优化方法。

\subsection{Walk-forward预测}

\textbf{日类型划分}。附件2的全年数据表明，日负载电量严格按工作日类型分离：周五与周六型日负载电量位于71.5--95.9~MWh，其他日型位于116.9--141.6~MWh，两个区间无任何交叉，全年365天无一例外。因此，将日类型分为两类不仅合理，而且是数据支持的最简洁分类。

\textbf{负载点预测}。采用最近$K_L$个同类型日的逐段均值。均值法的选择源于负载的日形态高度稳定——同类型日之间的主要差异是水平偏移而非形状变化，均值恰好能追踪这种水平漂移。$K_L=6$在1月验证窗口中给出最低实际费用。

\textbf{光伏点预测}。采用最近$K_P$天的逐段均值，$K_P=7$。光伏不按日类型分（天气与星期几无关），且需要更长的窗口平滑天气的日间波动。

\textbf{冷启动处理}。同类型历史日不足$K$时取全部可用；无任何历史时以附件1曲线（经验证恰为附件2全年逐段均值）作先验。

\subsection{经验残差场景：保留联合分布}

\textbf{为什么不用独立场景}。负载和光伏的预测误差在时间和空间上存在相关性：光伏大幅低于预测的日子（阴天）往往伴随特定的负载模式。若分别独立抽取各自的场景，将破坏这种联合结构，低估极端情况的概率。

\textbf{场景构建方法}。取最近$M=12$个同类型历史日，对每个历史日$h$，计算其在当时（仅用$<h$的数据）的点预测下的残差轨迹：
\begin{equation}
r^L_h = L_h - \hat L^0_h, \quad r^{PV}_h = PV_h - \widehat{PV}^0_h
\end{equation}
场景$\omega$的曲线为：
\begin{equation}\label{eq:scenario}
L_\omega = \text{clip}(\hat L^0_d + r^L_{h_\omega},\, 0,\, \infty), \quad PV_\omega = \text{clip}(\widehat{PV}^0_d + r^{PV}_{h_\omega},\, 0,\, \infty)
\end{equation}
负载与光伏的残差取\textbf{同一历史日}$h_\omega$，自然保留了两者的时间相关性和联合分布结构，无需做参数化分布假设或相关系数估计。

\subsection{SAA两阶段代理模型}

\subsubsection{模型为什么这样设计}

问题的决策时序天然分为两个阶段：0:00的购电承诺（不可撤回）和日内的储能调度（可根据信息调整）。这恰好是两阶段随机规划的经典结构——第一阶段决策在不确定性实现前做出，第二阶段追索在观测到实现后调整。

连续的误差分布无法直接求解。样本平均近似（SAA）用有限条历史残差场景的经验分布代替连续分布，将随机规划转化为一个规模放大但结构相同的确定性LP——这正是LP作为优化核的第二个结构红利：线性目标与约束使得SAA后仍然是LP，可被高效求解。

\subsubsection{48h时域：代替周期约束的设计}

经典的日调度模型常施加周期约束$S_{143} = S_0$，强制一天结束时储电量回到初值。但这一约束在问2的多日回测中造成两个问题：(1)~它阻止了储能在低价日多充、高价日多放的跨日套利；(2)~最后几段为了``回到$S_0$''可能做出违反经济最优的充放电。

本文的替代设计是将LP的时域从当天144段延伸到当天+次日共288段（48h），次日的负载和光伏用次日类型的点预测曲线。次日的LP变量自动通过目标函数给当天24:00的储电量``定价''——如果24:00储电量高，次日购电费节省；如果24:00储电量低，次日需要更多购电。这将储能的跨日转移从硬约束变为经济决策。

\textbf{稳健性验证}：24h/48h/72h时域的全年walk-forward回测表明，48h与72h的费用差仅0.004\%，而24h比48h高约5\%（主要来自日末效应），确认48h时域已足够。

\subsubsection{目标函数与变量结构}

\begin{equation}\label{eq:saa_obj}
\min \sum_{t \in d} p_t G^0_t + \frac{1}{M}\sum_{\omega=1}^{M}\bigg[\sum_{t \in d} 5p_t E_{\omega,t} + \sum_{t \in d+1}\big(p_t G_{\omega,t} + 5p_t E_{\omega,t}\big)\bigg] + \varepsilon\sum_{\omega,t}(C_{\omega,t}+D_{\omega,t}+W_{\omega,t})
\end{equation}

\textbf{第一阶段}（跨场景共享）：当天购电量$G^0_t \geq 0$，$t \in d$。

\textbf{第二阶段}（每场景独立）：$C_{\omega,t}, D_{\omega,t}, W_{\omega,t}, E_{\omega,t}, S_{\omega,t}$全时域；次日购电$G_{\omega,t}$，$t \in d+1$。

\textbf{wait-and-see近似}。储能追索无非预期性约束：每个场景的储能调度可以``看到''该场景的全部实现。这是对真实多阶段问题（储能在每段只知道当段真值）的一种松弛，使SAA给出的费用是真实费用的下界。但这恰好是合理的——SAA的职责仅是确定购电量$G^0$，储能的实际执行由后续的因果滚动LP负责。

\subsection{因果储能滚动控制}

\subsubsection{为什么不按日前计划执行储能}

SAA给出的储能充放电轨迹是基于场景分布的最优解，但真实的负载和光伏在每段实现时可能与任何一个场景都不同。若刚性执行日前计划，预测偏差将直接转化为紧急购电或富余浪费。

本文采用因果滚动LP：每10分钟段$t$开始时，以当前执行SOC $S_{t-1}$为初值、当段真值和剩余时域点预测为输入、\textbf{已冻结的购电量$G^0$不变}，求解一个确定性LP：
\begin{equation}
\min \sum_{\tau \geq t} 5p_\tau E_\tau + \sum_{\tau \in d+1} p_\tau G_\tau + \varepsilon\sum(C_\tau + D_\tau + W_\tau)
\end{equation}
仅执行首段的$C_t, D_t$。

\subsubsection{为什么是LP而非贪心规则}

储能的跨期耦合使贪心规则失效。考虑以下场景：当前段电价较低（$p_t=0.42$），下一段出现缺口需紧急购电（$5p_{t+1}=7$）。贪心规则在当前段无法``预见''下一段的缺口，可能把储能用于其他用途。而滚动LP覆盖当天+次日所有剩余段，能够识别出``现在充电、稍后放电补缺口''的全局最优策略。

\subsubsection{计算效率}

全年334天$\times$144段/天$\approx$48\,000个LP，每个约1\,400变量。利用HiGHS求解器，单次LP求解平均4.6~ms（最大6.3~ms），全年滚动控制在5分钟内完成。

\subsection{参数选择}

参数$K_L, K_P$的选择不使用预测MAE，而使用\textbf{1月实际购电费}作为判据——因为MAE不直接反映费用效果（在不对称惩罚下，一个MAE略高但分位数更合理的预测可能产生更低的费用）。

具体做法：对$K_L \in \{2,3,4,5,6\}$、$K_P \in \{3,4,5,6,7\}$的25个候选组合，各自从1月1日（SOC=6\,000）起跑完整的SAA+滚动控制流程，以1月8--31日（去除冷启动污染的首周）的实际总费用为判据，选定$K_L=6, K_P=7$。选定后2--12月固定不变。

\subsection{整点预报的信息价值}

问3引入附件3的光伏整点预报：在0:00/6:00/12:00/18:00四个时点，可获得未来24小时的整点瞬时光伏功率预报。经验证，``预报$k$小时''对应发布后第$k$个整点的\textbf{瞬时功率}（与附件2对齐的MAE为187~kW），通过线性插值转换为10分钟段值。

然而，单就日前预报而言，0:00发布的24h预报全日MAE为197~kW，反而不如问2中$K_P=7$日均值预测的153~kW。\textbf{附件3预报的价值不在于日前精度，而在于日内更新}：6:00更新使当日剩余段MAE从259~kW降至158~kW（$-39\%$），12:00更新进一步降至75~kW（$-66\%$）。

\subsection{重优化LP：调整变量与费用结构}

在预报时刻$h_0 \in \{6,12,18\}$:00，以当前执行SOC为初值，对剩余当天+次日求解含调整变量的SAA LP。引入分裂变量$\Delta^+_t, \Delta^-_t \geq 0$，调整购电量$G^a_t = G^0_t + \Delta^+_t - \Delta^-_t$。目标函数中当天剩余段的费用为：
\begin{equation}\label{eq:readjust_obj}
\sum_{t \geq t_0} \big[ p_t G^0_t + 1.5\,p_t\,\Delta^+_t - 0.5\,p_t\,\Delta^-_t \big]
\end{equation}
加上场景期望的紧急购电费与次日购电费。

这一费用结构的经济含义是：增购的有效价格为$1.5p$（比$5p$紧急购电便宜得多），减购可以``退回''$0.5p$。LP自动在$1.5p$增购与$5p$紧急购电之间进行权衡——当缺口概率足够大时，提前以$1.5p$增购是最优选择。

\textbf{提交规则}：重优化解中，仅$[h_0, \text{下一预报时刻})$区间的$G^a$被正式提交；之后段的解为临时决策，将被下一次重优化覆盖。

\subsection{电价预测层}

问4引入附件4的真实波动电价。经验证，附件1恰好是附件4的全年逐段均值（逐段最大差$5.2 \times 10^{-5}$元），即问2--3使用的常数电价已经是波动电价的最优无偏估计。

\textbf{电价点预测}：以最近$K_p$个同类型日的逐段均值$\bar p_t$为基准，乘以日水平因子$\lambda$：
\begin{equation}
\hat p_t = \lambda \cdot \bar p_t
\end{equation}
0:00取$\lambda=1$（日水平因子的lag-1自相关仅0.52，昨日因子无增益）；在6:00/12:00/18:00及储能滚动LP的每段，用当天已观测段最小二乘估计$\lambda$：
\begin{equation}
\lambda = \frac{\sum_{\tau < t} p_\tau \bar p_\tau}{\sum_{\tau < t} \bar p_\tau^2}, \quad \lambda \in [0.7, 1.3]
\end{equation}

$K_p=8$由1月费用判据选定。但电价预测窗口对费用的影响极小：$K_p$的全网格极差仅0.205\%，远低于$K_L, K_P$的1.56\%。

\subsection{联合残差场景扩展为三通道}

将残差场景从$(r^L, r^{PV})$扩展为$(r^L, r^{PV}, r^p)$，电价残差$r^p_h = p_h - \hat p_h$取同一历史日$h$，形成联合三通道场景。

在优化核中，电价不确定性通过按场景的代价系数进入LP：
\begin{itemize}
\item 计划购电费使用场景均值电价$\bar p^s_t = \frac{1}{M}\sum_\omega p_{\omega,t}$（因$G^0$跨场景共享，等价于按场景计费取期望）；
\item 紧急购电费按各场景$5p_{\omega,t}$取场景期望——这一选择至关重要：高价段的紧急购电变得更贵，使SAA在这些段自动买得更足。
\end{itemize}

\subsection{对微网运营商的建议}

\begin{enumerate}
\item \textbf{紧急购电不应作为绩效惩罚指标}。少量高频的紧急购电是不对称惩罚结构下的\textbf{最优风险配置}。真正需要警惕的是单次大额紧急购电（预测重大失误），而非高频小额紧急购电。

\item \textbf{预报资源的优先级}：6:00和12:00的光伏预报更新贡献了重优化93\%的价值。在预报投资有限时，应优先保障这两个时刻的预报质量，18:00的投入产出比极低。

\item \textbf{电价预测精度对费用影响有限}（$\approx 0.7\%$）。在波动电价环境下，降本的主要抓手仍在负载/光伏预测与储能调度策略。

\item \textbf{48h时域足够}。运营商无需维护超过次日的预测系统——48h与72h的费用差在万分之四以内。
\end{enumerate}

\subsection{模型优势}

\begin{enumerate}
\item \textbf{统一架构的结构稳定性}。四问共用同一LP构建器（约19\,000变量的SAA LP + 每段1\,400变量的滚动LP），改变的只是预测/场景层的输入。这使得不同问之间的费用差异可被\textbf{严格归因}到信息条件的变化。

\item \textbf{因果性的三层保证}。预测器内部断言、NaN毒化测试和集成级验证三层机制确保全程不泄漏未来信息。113项自动化测试覆盖从单个LP到全年回测的各个层次。

\item \textbf{经济学可解释性}。每个决策都能翻译为现实含义：80\%分位的承诺水平、0.47元/kWh的储能边际价值、18.4\%的信息租金、93\%的重优化价值来自6:00和12:00、电价波动代价的6/7不可避免。

\item \textbf{计算效率}。全年回测在5分钟内完成，使大规模敏感性分析成为可能。
\end{enumerate}

\subsection{模型局限与改进方向}

\begin{enumerate}
\item \textbf{储能追索的wait-and-see近似}松弛了非预期性约束。改进方向：按四个预报时刻（0:00、6:00、12:00、18:00）建立四阶段场景树，在第二阶段内部施加非预期性约束，代价是LP规模增大约$M^3$倍。

\item \textbf{负载预测不利用日内观测}。当前系统在重优化时仅更新光伏预报，负载仍用日前的$K_L$日均值。改进方向：用当天已实现的负载段对剩余段做偏差修正或条件预测。

\item \textbf{1月选参窗口不代表全年}。$K_L=6$在1月最优，但全年费用比$K_L=4$高0.89\%——冬季高负载、低光伏的1月不是全年的代表。改进方向：扩大选参窗口（如1--3月），或按季节切换参数。

\item \textbf{日类型仅两种}。未考虑节假日、极端天气等特殊情况。当前两类分类在附件2全年数据上无一例外，但推广至实际运营时需要补充更细致的分类。
\end{enumerate}

\subsection{模型推广性}

本文的框架具有良好的推广性：(1)~SAA两阶段代理模型可直接应用于任何``先承诺、后追索''结构的调度问题；(2)~联合残差场景方法不依赖参数化分布假设，适用于多源不确定性的建模；(3)~因果滚动LP作为在线决策层，可在任何承诺决策冻结后独立运行，不受优化核具体形式的约束。
